# TorchRotor-RANS v0.1 windfarm movie

23 turbines, 10 m/s inlet, 8 m grid, k-epsilon, recorded 0–60 s. Exploratory startup transient; experimental accuracy and steady state unverified. No trained weights. Rotor animation is display-only.

See model_card.md, configuration.json, numerical_audit.json and export_provenance.json. This is a presentation resource, not the complete simulation bundle. The full reproducible bundle is retained locally with geometry, source snapshot, float32 velocity samples and checkpoint. Existing resource versions are unchanged.
